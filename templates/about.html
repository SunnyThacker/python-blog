About This Blog

Welcome!

This is a simple blog platform built with Python, Flask, and Docker. It demonstrates how to create a containerized web application that can be easily deployed and scaled.

Features

  • 📝 Create and publish blog posts
  • 📖 Read full articles
  • 🗑️ Delete posts
  • 🐳 Fully containerized with Docker
  • ⚡ Fast and responsive interface

Technology Stack

  • Backend: Python with Flask
  • Frontend: HTML, CSS, JavaScript
  • Containerization: Docker
  • Port: 3000

Getting Started

To run this blog locally:

  1. Install Docker on your system
  2. Build the Docker image: docker build -t my-blog .
  3. Run the container: docker run -p 3000:3000 my-blog
  4. Visit http://localhost:3000 in your browser
